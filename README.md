# SecondBrain

A shared brain for Sunil and the agents working with them: plain markdown, read by humans and AI agents alike.

## How to use this repo (agents)

1. Before any real task, read this file (the map) and `rules.md`.
2. Open only the files the task needs.
3. Check here before asking Sunil something the brain might already answer.
4. When you learn something a later agent would need, add it to the right file with today's date (YYYY-MM-DD), or to a new file in `inbox/` if you're not sure where it belongs.

## Map

| Path | What's in it |
| --- | --- |
| `README.md` | This map. Update it when you add a new top-level file or folder. |
| `rules.md` | Standing rules for every agent. Change only when Sunil asks. |
| `inbox/` | Unsorted notes waiting to be filed. One file per note, named `YYYY-MM-DD-short-topic.md`. |

As the brain grows, add a row per file or folder (e.g. `decisions.md`, `preferences.md`, `projects/<name>.md`).

## Entry format

```markdown
## YYYY-MM-DD: Short title
What was learned or decided, and why. Who or what it came from, if useful.
```
